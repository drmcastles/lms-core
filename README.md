LMS Core System — Система управления обучением
Бэкенд-платформа для образовательных курсов на Spring Boot 3.2 и PostgreSQL. Проект реализует управление контентом, регистрацию студентов через Many-to-Many, систему проверки заданий и тестирование.

🛠 Технологический стек
Java 22

Spring Boot 3.2 (Data JPA, Web, Validation)

PostgreSQL 15 — Основная база данных

Docker & Docker Compose — Контейнеризация

Swagger (SpringDoc) — Интерактивное API

Lombok — Оптимизация кода

🚀 Инструкция по запуску
Вариант 1: Через Docker (Рекомендуемый)
Сборка проекта:

Bash

mvn clean package -DskipTests
Запуск инфраструктуры:

Bash

docker-compose up --build -d
Приложение будет доступно на порту 8081. Проверка статуса: docker-compose ps.

Вариант 2: Локальный запуск
База данных: Создайте в PostgreSQL базу данных lms_db.

Конфигурация: Настройте параметры в src/main/resources/application.properties:

server.port=8081

spring.datasource.url=jdbc:postgresql://localhost:5433/lms_db

spring.datasource.username=postgres

spring.datasource.password=1151

Запуск: Выполните команду mvn spring-boot:run.

🏗 Функциональные возможности
1. Управление обучением (Many-to-Many)
   Реализована полноценная связь между пользователями и курсами.

Студенты могут записываться на курсы и отслеживать свои подписки.

Автоматическая генерация связующих таблиц через Hibernate.

2. Система заданий (Assignments)
   Отправка решений: Студенты загружают ссылки на свои выполненные работы.

Контроль попыток: Встроенная логика блокирует повторную отправку одного и того же задания.

Оценка: Возможность выставления баллов преподавателем за присланные решения.

3. Тесты и викторины (Quizzes)
   Структура данных: Тест → Вопросы → Варианты ответов.

Сохранение результатов (QuizResult) с фиксацией итогового балла и времени завершения.

🧪 Тестирование и валидация
Автоматические тесты (LmsLogicTest.java)
Cascade Delete: Проверка автоматического удаления модулей при удалении курса.

Lazy Loading: Тестирование поведения ленивой загрузки данных вне сессии.

Integration: Проверка корректности записи студентов на курсы напрямую в БД.

Валидация API
Для проверки откройте Swagger UI. При отправке некорректных данных (например, пустого заголовка), система вернет 400 Bad Request, подтверждая работу jakarta.validation.

# LMS Core System — Система управления обучением

Бэкенд-платформа для образовательных курсов на Spring Boot 3.2 и PostgreSQL. Проект реализует управление контентом, гибкую систему регистрации пользователей на обучение, механизмы проверки заданий и систему тестирования.

## 🛠 Технологический стек
- **Java 22**
- **Spring Boot 3.2** (Data JPA, Web, Validation)
- **PostgreSQL 15** — основная база данных.
- **Docker & Docker Compose** — контейнеризация приложения и инфраструктуры.
- **Swagger (SpringDoc)** — интерактивная документация API.
- **Lombok** — оптимизация кода и уменьшение бойлерплейта.

## 🚀 Инструкция по запуску

### Вариант 1: Запуск через Docker (Рекомендуемый)
Для автоматического развертывания приложения и БД в изолированных контейнерах:
1. Соберите jar-файл:
   ```bash
   mvn clean package -DskipTests
Запустите инфраструктуру:

Bash

docker-compose up --build -d
Приложение будет доступно на порту 8081. Проверить статус: docker-compose ps.

Вариант 2: Локальный запуск
1. Клонирование репозитория

Bash

git clone [https://github.com/drmcastles/lms-core.git](https://github.com/drmcastles/lms-core.git)
cd lms-core
2. Подготовка базы данных Создайте в PostgreSQL базу данных lms_db.

3. Настройка подключения Отредактируйте src/main/resources/application.properties:

Properties

server.port=8081
spring.datasource.url=jdbc:postgresql://localhost:5433/lms_db
spring.datasource.username=postgres
spring.datasource.password=1151
spring.jpa.hibernate.ddl-auto=create
4. Запуск

Bash

mvn spring-boot:run
🏗 Функциональные возможности
Управление курсами и регистрация
Реализована связь Many-to-Many между пользователями и учебными программами:

Запись студентов на курсы через CourseService.

Автоматическое создание связующей таблицы в БД.

Просмотр списка активных курсов пользователя.

Система заданий (Assignments)
Реализован механизм сдачи и оценки практических работ:

Контроль попыток: Логика предотвращает повторную сдачу одного и того же задания одним пользователем.

Оценка: Функционал рецензирования и выставления баллов преподавателем.

Тестирование и викторины (Quizzes)
Иерархическая структура: Тест -> Вопросы -> Варианты ответов.

Сохранение результатов (QuizResult) с привязкой к пользователю, фиксацией баллов и времени прохождения.

🧪 Тестирование и валидация
Автоматические тесты
В проекте настроены тесты (LmsLogicTest.java), проверяющие критическую логику:

Cascade Delete: Удаление курса влечет автоматическое удаление всех связанных модулей.

Lazy Loading: Проверка корректности ленивой загрузки данных вне сессии.

Integration Check: Проверка сохранения связей Many-to-Many в базе данных.

Валидация API (Swagger)
Для тестирования ограничений (Критерий 10):

Откройте Swagger UI.

Попробуйте отправить POST-запрос с некорректными данными (например, пустой email).

Система вернет 400 Bad Request, подтверждая работу jakarta.validation.

# LMS Core System — Система управления обучением

Бэкенд-платформа для образовательных курсов на **Spring Boot 3.2** и **PostgreSQL**. Реализует управление контентом, регистрацию студентов через Many-to-Many, систему проверки заданий и тестирование.

---

## 🛠 Технологический стек
* **Java 22**
* **Spring Boot 3.2** (Data JPA, Web, Validation)
* **PostgreSQL 15** (Основная БД)
* **Docker & Docker Compose** (Контейнеризация)
* **Swagger (SpringDoc)** (Интерактивное API)
* **Lombok** (Оптимизация кода)

---

## 🚀 Инструкция по запуску

### Вариант 1: Через Docker (Рекомендуемый)
Для запуска приложения и БД в изолированных контейнерах:
1. Соберите проект:
   ```bash
   mvn clean package -DskipTests
Запустите инфраструктуру:

Bash

docker-compose up --build -d
Приложение доступно на порту 8081. Статус можно проверить командой docker-compose ps.

Вариант 2: Локальный запуск
Создайте в PostgreSQL базу данных lms_db.

Настройте подключение в src/main/resources/application.properties:

server.port=8081

spring.datasource.url=jdbc:postgresql://localhost:5433/lms_db

spring.datasource.username=postgres

spring.datasource.password=1151

Запустите через Maven:

Bash

mvn spring-boot:run
🏗 Функциональные возможности
1. Управление обучением (Many-to-Many)
   Реализована полноценная связь между пользователями и курсами.

Студенты могут записываться на курсы и отслеживать свои подписки.

Автоматическая генерация связующих таблиц через Hibernate.

2. Система заданий (Assignments)
   Отправка решений: Студенты загружают ссылки на свои работы.

Контроль попыток: Логика блокирует повторную отправку одного и того же задания.

Оценка: Возможность выставления баллов за присланные решения.

3. Тесты и викторины (Quizzes)
   Структура данных: Тест → Вопросы → Варианты ответов.

Сохранение результатов (QuizResult) с фиксацией баллов и времени завершения.

🧪 Тестирование и валидация
Автоматические тесты (LmsLogicTest.java)
Cascade Delete: Проверка удаления всех модулей при удалении курса.

Lazy Loading: Тестирование поведения ленивой загрузки данных.

Integration: Проверка записи студентов на курсы напрямую в БД.

Валидация API
Для проверки откройте Swagger UI. При отправке некорректных данных (например, пустой заголовок курса), система вернет 400 Bad Request, подтверждая работу jakarta.validation.
